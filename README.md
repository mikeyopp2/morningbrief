# Morning brief

Daily morning brief (shul times at Ayin L'Tzion, Thornhill weather, TTC subway delays, Toronto sports), published to GitHub Pages each morning Sunday to Friday.

- Today: `index.html`
- Past days: `archive.html` and `briefs/`
- `build.py` publishes a day: `python3 build.py YYYY-MM-DD fragment.html`
